# 🧪 QA Journey 2026 — Manual to Automation in 30 Days

Currently employed, learning QA in my spare time (1 hr weekdays, more on weekends).
Documenting my journey from manual testing basics to job-ready Manual + Automation QA.

## 🎯 Goal
Become a modern QA engineer — manual testing, STLC on a real-world style project,
Jira + Zephyr, GitHub workflow, and automation basics — in one month.

## ✅ Where I'm starting from
Already covered (Module 1 — Software Testing Concepts):
- SDLC & STLC, Waterfall/Spiral/V-Model
- QA vs QC vs QE
- Levels of testing, White/Black box testing
- Static & Dynamic testing, Verification & Validation
- Functional & Non-functional testing, Test design techniques

## 🗺️ Roadmap
- **Week 1** — STLC deep dive + pick a real-world style project (demo app)
- **Week 2** — Test scenarios, test cases, execution, bug reporting on the project
- **Week 3** — Agile/Scrum + Jira + Zephyr (epics, sprints, test cycles)
- **Week 4** — Automation basics + HR interview prep

## 📁 Repo structure
- `/notes` — daily/weekly learning notes
- `/test-cases` — test scenarios & test case sheets
- `/bug-reports` — bugs logged against the practice project
- `/jira-screenshots` — sprint boards, tickets, Zephyr test cycles
- `/automation` — scripts (Week 4 onward)
